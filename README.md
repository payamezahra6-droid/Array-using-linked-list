# Array Using Linked List (Java)

## Description
This project implements an array-like data structure using a linked list in Java. It demonstrates how to store and manage elements using nodes instead of a built-in array.

## Features
- Insert elements
- Display all elements
- Access elements using an index
- Update elements at a specific index
- Delete elements using an index
- Get the total number of elements
- Handle invalid indexes

## Classes
- **Node.java** — Stores data and a reference to the next node.
- **Array.java** — Implements array-like operations using a linked list.
- **Main.java** — Runs the program and demonstrates its functionality.

## Concepts Used
- Data Structures and Algorithms (DSA)
- Linked Lists
- Classes and Objects
- Node-based memory management
- Insertion, deletion, searching by index, and updating

## Technologies
- Java
- IntelliJ IDEA

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. View the output in the console.

## Learning Objective
The objective of this project is to understand how a linked list can be used to implement array-like operations and to practice basic data structure concepts in Java.
